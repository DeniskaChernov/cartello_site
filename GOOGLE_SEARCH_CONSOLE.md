# Google Search Console и органический поиск

## Проверено и опубликовано 25 сентября 2026

- Основной адрес: `https://cartello.uz/`; canonical уже присутствует в исходном HTML.
- Главная, `robots.txt` и `sitemap.xml` доступны по HTTPS с кодом 200.
- `robots.txt` разрешает обход и указывает `https://cartello.uz/sitemap.xml`.
- Sitemap содержит одну реальную страницу — главную. Дата последнего изменения
  обновлена после исправления SEO-разметки на 2026-09-25. Не обновляйте её автоматически
  при каждом deploy: дата должна соответствовать существенному изменению страницы.
- Удалены hreflang ru/uz/x-default, которые указывали на один и тот же URL.
  Переключатель языка сохранён. Возвращать hreflang следует после появления отдельных
  индексируемых URL переводов и взаимных ссылок между ними.
- Существующие title, description и разметка WebSite/AutomotiveBusiness сохранены.
- Реклама, Google Ads и платные кампании не подключались.

## Состояние Search Console

Настройки ресурса Cartello ещё не изменены: доступный Chrome показывал только Google-
аккаунты Denis и BentenTrade, затем браузер отключился от управления. Существующая
DNS-запись Google verification сохранена, но сама по себе не подтверждает, что текущий
аккаунт имеет доступ к ресурсу. Sitemap через Search Console ещё не отправлен,
проверка URL и запрос индексирования ещё не выполнены.

После входа в `cartellogroup@gmail.com`:

1. Найти существующий ресурс `cartello.uz` (предпочтительно доменный ресурс) и проверить
   доступ владельца. Не создавать дубликат, если нужный ресурс уже существует.
2. Открыть «Файлы Sitemap», проверить прежние отправки и отправить
   `https://cartello.uz/sitemap.xml`, если такой отправки ещё нет. Проверить статус.
3. Выполнить «Проверка URL» для `https://cartello.uz/`, изучить текущую индексацию,
   выбранный Google canonical и выполнить проверку опубликованной страницы.
4. При доступности страницы запросить индексирование. Это запрос обхода, а не обещание
   немедленного включения в индекс или определённой позиции.
5. Проверить отчёты «Страницы», HTTPS, Core Web Vitals, меры вручную и безопасность.
   Не инициировать удаление URL, смену адреса сайта или отказ от ссылок без оснований.

## Следующие работы для роста поиска

- Проанализировать реальные запросы и страницы в отчёте эффективности GSC.
- Проверить видимость услуг в отрендеренном Google HTML. Сейчас сайт использует React
  на клиенте; Google требуется выполнить JavaScript для основного содержимого.
- Подготовить отдельные полезные страницы услуг с реальными ценами, примерами работ,
  описанием процесса и вопросами клиентов; не создавать массовые страницы с заменой
  только ключевых слов. Добавить внутренние ссылки и sitemap для опубликованных URL.
- При отдельных русских и узбекских URL добавить правильные hreflang и canonical.
- Проверить Google Business Profile, адрес, телефоны и часы работы по данным владельца.
  Не придумывать отзывы, оценки, филиалы и гарантии.
- По результатам измерений оптимизировать загрузку изображений и Core Web Vitals.

Настройка GSC помогает диагностировать и исправлять индексацию; она не гарантирует топ.
